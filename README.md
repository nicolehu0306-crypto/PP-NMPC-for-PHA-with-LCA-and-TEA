# PP-NMPC-for-PHA-with-LCA-and-TEA
Simulation code for "Prescribed performance nonlinear model predictive control of fed-batch polyhydroxyalkanoate production with life cycle and techno-economic assessment"

DF.py is the Python code to fit the kinetics model with experimental data. Change the 'EXCEL_PATH' and 'OUTPUT_DIR' to the ones you use.

PP-NMPC is the code for the control of the nominal kinetics model.
